# Neon Arcade

A neon-style arcade launcher with multiple mini-games built in plain JavaScript.

## Included games
- Cyber Circuit
- Neon Dodge
- Tag
- Pong
- Retro Scavenger
- Asteroid Blaster

## How to run
Open `index.html` in a browser.

## Notes
Movement has been updated to feel smooth and continuous instead of blocky.
